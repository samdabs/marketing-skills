# Marketing skills for Claude

Three plain-text skills for local SEO and AI search work. Each one is a folder with a `SKILL.md` file that Claude Code and Claude read and follow.

| Skill | What it does |
|---|---|
| `ai-footprint-audit` | Checks what the web and AI tools say about a business, person or employer, tests it for accuracy, and gives a ranked fix list with sources. |
| `local-seo-audit` | A one-page audit of a Google Business Profile and the signals around it, with a before and after check. |
| `lead-finder-free` | Builds a short, researched prospect list from free sources and drafts outreach for a person to send. Nothing is sent automatically. |

## Use them

1. Download this repo.
2. Copy the folders inside `skills/` into your Claude skills folder (`~/.claude/skills/` on Mac and Linux).
3. Start a new session and ask for the skill by name, for example: "run an AI footprint audit on [business], [website], [town]".

## What is not here

No client names, no prospect lists, no keys. Every skill tells Claude to cite a source for each finding and to mark anything it could not check.
