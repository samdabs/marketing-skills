# AI footprint audit

One method for any target: a client, your own business, a personal brand, or an employer.

## Inputs
Get these four. Ask once if one is missing.
1. Name
2. Website
3. Town and country
4. Main services (for a person: role and what they want to be known for)

## Method
1. Write the target in one line and pick the mode: business, personal brand, or employer.
2. Search the web for each of these and save every URL with the date:
   - the exact name
   - name plus town
   - name plus reviews
   - name plus each main service
   - best [service] in [town]
   - [service] near [town]
3. What AI says. Claude cannot see a private ChatGPT answer. Read what AI answers draw from (top results, review sites, directories, the site's own pages) and ask the user to paste the answers they get from ChatGPT, Gemini and Perplexity for the same questions. Never invent an AI answer. Mark anything unseen as unverified.
4. Accuracy check. Compare address, phone, hours, services, prices, founding year and owner against the business's own site. List every mismatch.
5. Where it appears. Check Google Business Profile, Bing Places, Apple Business Connect, Yelp, Facebook, LinkedIn, industry directories, the local chamber and review sites. Mark each as correct, wrong, or missing.
6. Who shows up instead. Name the top 3 to 5 competitors in the results and say why in plain terms: more reviews, more listings, clearer service pages, press, a stronger site.
7. Write the fix list, quickest wins first. Each item has what to do, exact clicks, time, cost (free first) and how to prove it worked.
8. Save the findings with the date as a baseline so the next run can be compared.

## Rules
- Every finding has a source URL and a date. No source, no claim.
- Never invent a review, ranking, quote or AI answer.
- Free fixes first. Ask before suggesting anything that costs money.
- If a business already ranks well, treat changes to its name, website address or main category as a risk and say so.
- Write for a reader with no SEO knowledge.

## Output
One page: summary in 3 lines, what the web and AI say, accuracy mismatches, where it appears, who shows up instead and why, the ranked fix list, the baseline.

## Mistakes to avoid
- Presenting a guess about ChatGPT as a fact.
- A long list with no order.
- Skipping the accuracy check. Wrong facts that AI repeats cost the most.
